# Power Protection and Resilience

## Overview

Critical home lab systems are connected to an Uninterruptible Power Supply (UPS).

## Protected Equipment

- Network router
- Proxmox server
- Synology NAS
- Raspberry Pi systems

## Purpose

The UPS provides temporary battery power during short outages.

It helps reduce the risk of:

- Filesystem corruption
- Unexpected VM shutdowns
- NAS storage issues
- Network outages
- Service downtime

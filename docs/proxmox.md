# Proxmox Virtualization

## Overview

Proxmox VE serves as the primary virtualization platform within the home lab.

It is used to host Windows, Linux, and cybersecurity-focused virtual machines.

## Current Virtual Machines

- Windows 11 client
- Ubuntu Linux
- T-Pot Honeypot

## Proxmox Features Used

- Virtual machine creation
- CPU allocation
- Memory allocation
- Virtual disks
- Linux bridges
- Local storage
- NFS storage
- Console access
- VM startup and shutdown
- Resource monitoring

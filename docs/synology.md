# Synology NAS

## Overview

The Synology NAS provides centralized storage and network services for the home lab.

## Current Services

- File storage
- Synology Drive
- Synology Photos
- NFS
- Backup storage
- Media services

## Home Lab Integration

The NAS provides network-based storage that can be accessed by other systems within the home lab.

It is also used as part of the virtualization and backup environment.

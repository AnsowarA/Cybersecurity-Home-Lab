# Security Services

## Overview

The home lab includes several cybersecurity tools used for security monitoring, detection, experimentation, and analysis.

## T-Pot Honeypot

T-Pot is deployed as a virtual machine within Proxmox.

It provides an environment for observing honeypot activity and security telemetry.

## Wazuh SIEM

Wazuh provides centralized endpoint monitoring and security analysis.

The full Wazuh project is documented separately:

[Wazuh SIEM Home Lab](https://github.com/AnsowarA/Wazuh-SIEM-Home-Lab)

## Security Skills Practiced

- Honeypot technologies
- Security event analysis
- Log analysis

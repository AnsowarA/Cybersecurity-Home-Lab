# Network Infrastructure

## Overview

The home lab uses multiple physical networking devices to provide wired connectivity between servers, storage systems, Raspberry Pi devices, and endpoint systems.

## Current Network Components

- Primary router
- Secondary router
- Ethernet switch
- Proxmox server
- Synology NAS
- Raspberry Pi systems
- Windows desktop systems

## Networking Concepts Practiced

- TCP/IP
- Ethernet
- Routing
- Switching
- DNS
- Network troubleshooting
- Linux bridges
- Internal service connectivity

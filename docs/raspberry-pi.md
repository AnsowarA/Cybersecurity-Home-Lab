# Raspberry Pi Infrastructure

## Overview

Raspberry Pi systems provide lightweight, always-on infrastructure services within the home lab.

## Current Services

- Pi-hole
- Nginx reverse proxy
- Uptime Kuma

## Pi-hole

Pi-hole provides network-level DNS filtering and DNS query visibility.

## Nginx Reverse Proxy

Nginx provides reverse proxy functionality for selected internal web services.

## Uptime Kuma

Uptime Kuma monitors the availability and response time of home lab services.
